# Code of Conduct

## The short version

Be decent. This is a project about a cartoon bear on an ice cube — nothing here
is worth being unpleasant to another person over.

## What is expected

- Assume good faith. Most disagreements are misunderstandings.
- Critique code and ideas, not people.
- Accept that maintainers may decline a change. "No" is a normal answer in open
  source and is not a personal judgement.
- Respect that contributors have different levels of experience, different
  native languages, and different amounts of free time.

## What is not acceptable

- Harassment, insults, or personal attacks of any kind.
- Discriminatory language or imagery, including anything targeting someone's
  identity or background.
- Publishing other people's private information.
- Sustained disruption of discussions or deliberate derailing of issues.

## Scope

This applies to everything in this repository — issues, pull requests,
discussions, commit messages, and code comments — and to any space where someone
is representing the project.

## Reporting

If someone is behaving badly, contact the maintainer privately through the
repository's **Security → Report a vulnerability** form, or by opening an issue
if the matter is not sensitive. Reports will be handled discreetly.

Maintainers may edit, hide, or delete content that breaks these rules, and may
block accounts that keep breaking them.

---

If you would like a more formal document to point at, the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
covers the same ground in much more detail and this project considers itself
aligned with it.
